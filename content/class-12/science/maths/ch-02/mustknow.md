## Must-know lines and definitions

- **Principal value:** the value of an inverse trig function that lies in its principal branch.
- **Range of $\sin^{-1}x$:** $\left[-\dfrac\pi2,\dfrac\pi2\right]$.
- **Range of $\cos^{-1}x$:** $[0,\pi]$.
- **Range of $\tan^{-1}x$:** $\left(-\dfrac\pi2,\dfrac\pi2\right)$, open at both ends.
- **Range of $\cot^{-1}x$:** $(0,\pi)$, open at both ends.
- **Range of $\sec^{-1}x$:** $[0,\pi]-\left\{\dfrac\pi2\right\}$.
- **Range of $\operatorname{cosec}^{-1}x$:** $\left[-\dfrac\pi2,\dfrac\pi2\right]-\{0\}$.
- **Domain of $\sin^{-1}x$ and $\cos^{-1}x$:** $[-1,1]$.
- **Domain of $\sec^{-1}x$ and $\operatorname{cosec}^{-1}x$:** $\mathbb{R}-(-1,1)$.
- **Never negative:** $\cos^{-1}$, $\cot^{-1}$, $\sec^{-1}$.
- **$\sin^{-1}x$ is not:** $(\sin x)^{-1}=\dfrac{1}{\sin x}$.
- **Not in boards 2026–27:** sum formulas such as $\tan^{-1}x+\tan^{-1}y$.

## Key formulas

:::formula $\sin^{-1}(-x)$
$\sin^{-1}(-x)=-\sin^{-1}x$
:::

:::formula $\cos^{-1}(-x)$
$\cos^{-1}(-x)=\pi-\cos^{-1}x$
:::

:::formula $\tan^{-1}(-x)$
$\tan^{-1}(-x)=-\tan^{-1}x$
:::

:::formula $\cot^{-1}(-x)$
$\cot^{-1}(-x)=\pi-\cot^{-1}x$
:::

:::formula $\sec^{-1}(-x)$
$\sec^{-1}(-x)=\pi-\sec^{-1}x$
:::

:::formula When $\sin^{-1}(\sin\theta)=\theta$
only if $\theta\in\left[-\dfrac\pi2,\dfrac\pi2\right]$
:::

:::formula When $\cos^{-1}(\cos\theta)=\theta$
only if $\theta\in[0,\pi]$
:::

:::formula When $\tan^{-1}(\tan\theta)=\theta$
only if $\theta\in\left(-\dfrac\pi2,\dfrac\pi2\right)$
:::

:::formula $\sin^{-1}x+\cos^{-1}x$
$\sin^{-1}x+\cos^{-1}x=\dfrac\pi2$
:::

:::formula $\tan^{-1}x+\cot^{-1}x$
$\tan^{-1}x+\cot^{-1}x=\dfrac\pi2$
:::

:::formula Simplest form of $\tan^{-1}\dfrac{\cos x}{1-\sin x}$
$\dfrac\pi4+\dfrac x2$
:::

:::formula Simplest form of $\tan^{-1}\dfrac{\sqrt{1+x^2}-1}{x}$
$\dfrac12\tan^{-1}x$
:::

:::formula Substitution for $\sqrt{a^2-x^2}$, $a^2+x^2$, $\sqrt{x^2-a^2}$
$x=a\sin\theta$,   $x=a\tan\theta$,   $x=a\sec\theta$
:::

## Answer skeletons

Step marks in square brackets are the usual CBSE split (estimates).

## Quick 1-mark facts (MCQ, A–R)

- Value of $\cos^{-1}\left(-\dfrac12\right)$: $\dfrac{2\pi}{3}$.
- Value of $\sin^{-1}\left(-\dfrac12\right)$: $-\dfrac\pi6$.
- Value of $\cot^{-1}(-1)$: $\dfrac{3\pi}{4}$.
- Value of $\sec^{-1}(-2)$: $\dfrac{2\pi}{3}$.
- Value of $\sin^{-1}\left(\sin\dfrac{2\pi}{3}\right)$: $\dfrac\pi3$.
- Value of $\cos^{-1}\left(\cos\dfrac{7\pi}{6}\right)$: $\dfrac{5\pi}{6}$.
- Value of $\tan^{-1}\left(\tan\dfrac{3\pi}{4}\right)$: $-\dfrac\pi4$.
- Value of $\tan^{-1}\sqrt3-\cot^{-1}(-\sqrt3)$: $-\dfrac\pi2$.
- Value of $\cos^{-1}\dfrac12+2\sin^{-1}\dfrac12$: $\dfrac{2\pi}{3}$.
- Value of $\sin\left(\dfrac\pi3-\sin^{-1}\left(-\dfrac12\right)\right)$: $1$, since the angle is $\dfrac\pi2$.
- Value of $\sin\left(2\sin^{-1}\dfrac35\right)$: $\dfrac{24}{25}$.
- Value of $\tan\left(\cos^{-1}\dfrac45\right)$: $\dfrac34$.
- Domain of $\sin^{-1}(2x-1)$: $[0,1]$.
- Domain of $\cos^{-1}(3x-2)$: $\left[\dfrac13,1\right]$.

## Mark-losing traps

:::tip Negative answer from $\cos^{-1}$
$\cos^{-1}$, $\cot^{-1}$ and $\sec^{-1}$ are never negative: use $\pi-\dots$ for a negative argument.
:::

:::tip Blind cancelling
$\sin^{-1}(\sin\theta)=\theta$ only inside the branch; check first.
:::

:::tip Degrees
Principal values are written in radians with $\pi$, not in degrees.
:::

:::tip Open interval for $\tan^{-1}$
$\pm\dfrac\pi2$ are never values of $\tan^{-1}x$; $0$ and $\pi$ are never values of $\cot^{-1}x$.
:::
