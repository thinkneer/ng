# Ch 11 · Dual Nature of Radiation and Matter — formulas

## Photoelectric effect

:::formula Photoelectric effect
Photon: $E=h\nu=\dfrac{hc}{\lambda}$;   $E(\text{eV})=\dfrac{1240}{\lambda(\text{nm})}$;   $p=\dfrac h\lambda=\dfrac Ec$<br>
Einstein: $K_\text{max}=h\nu-\phi_0=eV_0$;   $\phi_0=h\nu_0=\dfrac{hc}{\lambda_0}$<br>
$V_0=\dfrac he\nu-\dfrac{\phi_0}{e}$ (slope $h/e$, intercept $\nu_0$);   photons per second $n=\dfrac{P}{h\nu}$
:::

- No emission below $\nu_0$ however intense; photocurrent ∝ intensity; $K_\text{max}$ depends on ν not intensity; emission instantaneous (~$10^{-9}$ s).
- Graphs: more intensity → higher saturation, same $V_0$; higher ν → more negative $V_0$, same saturation. $V_0$ vs ν: straight line, same slope for all metals.
- Alkali metals have low work function (Cs ≈ 2.1 eV); Zn, Cd need UV.

## Matter waves

:::formula de Broglie
$\lambda=\dfrac hp=\dfrac{h}{mv}=\dfrac{h}{\sqrt{2mK}}=\dfrac{h}{\sqrt{2mqV}}$;   electron through $V$: $\lambda=\dfrac{1.227}{\sqrt V}$ nm
:::

- Same $V$: $\lambda_e>\lambda_p>\lambda_\alpha$. Same $K$: lighter particle has larger λ. Not in boards: Davisson–Germer experiment.
- Constants: $h=6.63\times10^{-34}$ J s, $e=1.6\times10^{-19}$ C, $m_e=9.1\times10^{-31}$ kg, $hc=1240$ eV nm.
