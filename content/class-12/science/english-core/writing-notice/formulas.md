# Notice — format sheet

## Format and marks

:::formula Notice — parts in order
Box · Issuing body (centred) · NOTICE (centred) · Date (left, in full) · TITLE (caps) · Body ~50 words · Name · Designation
:::

:::formula Notice — marks split (4)
Format 1 · Content 2 (five Ws: what, when, where, for whom, contact) · Expression 1 (grammar, formal tone, no I/you)
:::

## Value points by notice type

:::formula Event notice — value points
Name of event · date · time · venue · who may take part · registration / what to bring · deadline · contact the undersigned
:::

:::formula Lost-and-found notice — value points
Item · brief description (colour, make, contents) · where and when lost/found · whom to return it to / claim it from · reward or identification line
:::

:::formula Meeting notice — value points
Whose meeting · date · time · venue · agenda ("to discuss…") · request to attend on time · contact for suggestions
:::
