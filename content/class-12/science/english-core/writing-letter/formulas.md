# Formal letters — format sheet

:::formula Formal letter — parts in order
Sender's address · Date · Receiver's designation and address · Subject · Salutation (Sir, / Sir/Madam,) · P1 purpose · P2 details · P3 action · Yours sincerely, · Name (+ role)
:::

:::formula Letter — marks split (5)
Format 1 · Content 2 (points asked, in the right paragraph, specific) · Expression 2 (grammar, register, coherence, 120–150 words)
:::

:::formula Editor letter — value points
Esteemed-newspaper opening · the issue · two or three specifics (place, frequency, effects, who suffers) · causes · suggestions · who should act · hope for prompt action
:::

:::formula Complaint letter — value points
Purpose · item/service · date · bill or order number · exact defect or lapse · inconvenience caused · one remedy (replace/repair/refund) · time frame · bill enclosed · polite close
:::

:::formula Job application — value points
Advertisement reference (paper, date) · post · qualification · experience · two strengths matching the post · bio-data enclosed · request for interview
:::

:::formula Bio-data — rows
Name · Date of birth · Address · Phone / email · Educational qualifications (exam, board, year, marks %) · Experience · Skills · Languages known · References (optional)
:::
