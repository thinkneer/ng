# Case-based passage — method sheet

:::formula Q2 at a glance
Factual passage ~300–350 words + table/chart/graph · 8–10 items · 10 marks · 12–15 minutes · read the visual first
:::

:::formula Visual-first checklist
Title · what is measured · unit · groups and period · largest and smallest · trend · footnote (sample size, rounding)
:::

:::formula Data arithmetic
Difference = larger − smaller · change = last − first · % figures → percentage points · ×2 = doubled, ÷2 = halved · do it on paper
:::

:::formula Item types and where to look
Facts → first paragraph · values, extremes, trends → the visual · explanations and conclusions → last paragraphs · vocabulary → named paragraph, same part of speech · inference → what the numbers support only
:::

:::formula Inference language
"The data suggests that…" · "…is more common among…" · "…rose steadily while…fell" · "The survey shows a link, not a cause"
:::
