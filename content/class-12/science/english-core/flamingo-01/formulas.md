# The Last Lesson — value points

:::formula The Last Lesson — plot in six beats
Franz late, unprepared · bulletin board and Wachter · silent classroom, Sunday clothes, villagers · announcement: last French lesson · lesson on language, blame shared · writing, Hauser spelling, "Vive La France!" at noon
:::

:::formula Changes in school that day — value points
Silence like Sunday morning · M. Hamel kind instead of angry · green coat, frilled shirt, silk cap · villagers on back benches · Hauser with primer → last lesson, farewell, respect for teacher and country
:::

:::formula Franz's transformation — value points
Dreaded participles, loved outdoors · thunderclap of the news · regrets truancy (birds' eggs, Saar) · books become old friends · forgets the ruler, pities M. Hamel · understands the lesson easily · learns the value of what is lost
:::

:::formula Language as key to the prison — value points
Language carries identity and culture · conqueror imposes German to erase French identity · keeping the language keeps freedom alive · M. Hamel: guard French, never forget it · pigeons in German = absurdity of linguistic chauvinism
:::

:::formula Procrastination in Alsace — value points
"Time enough, tomorrow" habit · children skipped lessons · parents sent children to farms/mills for money · M. Hamel gave holidays, used boys for flowers · result: cannot write their own language when it is taken away
:::

:::formula M. Hamel — character value points
Forty years' service · strict (ruler) yet gentle on the last day · honest, blames himself · passionate about French · fixes the room in memory · chokes, writes "Vive La France!" · dignified patriot
:::

:::formula Role of the villagers — value points
Former mayor, postmaster, Hauser · thank M. Hamel for faithful service · honour the country no longer theirs · regret neglecting school · Hauser spelling with the children — community's shared loss
:::
