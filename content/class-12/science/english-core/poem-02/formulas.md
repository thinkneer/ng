# Keeping Quiet — value points

:::formula Keeping Quiet — the poem in six moves
Count to twelve, keep still · exotic moment without rush or engines · fishermen spare whales, salt-gatherer sees his hands · wars stop, clean clothes, brothers in shade · not death but life — understand ourselves · Earth's lesson, count again, poet goes
:::

:::formula Stillness requested — value points
No speaking in any language · no moving arms · twelve = clock, year, cycle · sudden strangeness unites · exotic = rare, never experienced · without engines = no hurry
:::

:::formula Harm that would stop — value points
Fishermen and whales (nature) · salt-gatherer's hurt hands (worker/self) · green wars (environment) · gas and fire (weapons) · victory with no survivors (total war) · clean clothes, brothers in the shade (peace)
:::

:::formula Life, not death — value points
No total inactivity · no truck with death · life is what it is about · single-minded about keeping life moving · never understand ourselves · threaten ourselves with death · interrupt this sadness
:::

:::formula Earth's lesson — value points
Winter looks dead · spring proves alive · stillness hides life getting ready · pause = renewal, not end · hope
:::

:::formula Devices and themes — value points
Symbolism (twelve, engines, clean clothes, winter) · imagery · paradox · repetition · antithesis · free verse, direct address · introspection · peace · brotherhood · environment · anti-haste
:::
