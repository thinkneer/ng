# Ch 1 · Sexual Reproduction in Flowering Plants — key facts

## Counting cells and nuclei

:::formula Embryo sac count
7 cells (3 antipodals + central cell + 2 synergids + egg), 8 nuclei (central cell has 2 polar nuclei).
:::

:::formula Divisions to make the embryo sac
1 meiosis (MMC → 4 megaspores) + 3 free-nuclear mitoses (1 → 2 → 4 → 8 nuclei).
:::

:::formula Male gametes per pollen grain
1 pollen grain → 1 vegetative cell + 1 generative cell → generative cell divides once → 2 male gametes.
:::

## Ploidy table

| Structure | Ploidy |
|---|---|
| Pollen mother cell, megaspore mother cell, nucellus | 2n |
| Microspore, pollen cells, male gametes, megaspore | n |
| Egg, synergids, antipodals, each polar nucleus | n |
| Zygote, embryo | 2n |
| Primary endosperm nucleus, endosperm | 3n |
| Integuments, seed coat, ovary wall, pericarp, perisperm | 2n |

- Chromosome trick: if nucellus = 2n = 24, endosperm = 36, egg/antipodal = 12, embryo = 24.

## What becomes what after fertilisation

| Before | After |
|---|---|
| Ovule | Seed |
| Integuments | Seed coat (testa, tegmen) |
| Micropyle | Pore in seed coat (water, O₂ entry) |
| Zygote | Embryo |
| Primary endosperm cell | Endosperm |
| Nucellus (if it persists) | Perisperm |
| Ovary | Fruit |
| Ovary wall | Pericarp |
| Synergids, antipodals | Degenerate |

## Facts to remember

- Anther: bilobed, dithecous, tetrasporangiate; wall: epidermis → endothecium → middle layers → tapetum.
- Pollen shed 2-celled in over 60% of angiosperms; size 25–50 µm.
- Pollen viability: rice, wheat ≈ 30 min; some Rosaceae, Leguminosae, Solanaceae: months; storage −196 °C.
- Outbreeding devices: timing (dichogamy), position, self-incompatibility, unisexual flowers.
- Monoecious (castor, maize) stops autogamy only; dioecious (papaya) stops autogamy and geitonogamy.
- Endosperm: free-nuclear → cellular; coconut water = free-nuclear, kernel = cellular.
- Embryo stages: proembryo → globular → heart-shaped → mature.
- Seed moisture 10–15%; *Lupinus arcticus* ≈ 10,000 yr; *Phoenix dactylifera* ≈ 2000 yr.
- False fruits: apple, strawberry, cashew. Parthenocarpy: banana. Polyembryony: citrus, mango.
