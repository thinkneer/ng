# Ch 5 · Molecular Basis of Inheritance — relations and facts

## Quantities

:::formula Length of DNA
Length = number of base pairs × 0.34 nm. Human: 6.6 × 10⁹ bp → ≈ 2.2 m; *E. coli*: 4.6 × 10⁶ bp → ≈ 1.36 mm.
:::

:::formula Chargaff's rule
A = T, G = C; A + G = T + C (purines = pyrimidines). If A = 20 %, then T = 20 %, G = C = 30 %.
:::

:::formula Turns of the helix
Number of turns = base pairs ÷ 10 (pitch 3.4 nm holds 10 bp).
:::

:::formula Hydrogen bonds in a duplex
Total H-bonds = 2 × (number of A–T pairs) + 3 × (number of G–C pairs).
:::

:::formula Codons
4³ = 64 codons: 61 code for amino acids, 3 stop (UAA, UAG, UGA); AUG = start + methionine.
:::

## Facts to remember

- Lac operon: i → repressor; z → β-galactosidase; y → permease; a → transacetylase; inducer = lactose.
- HGP: 1990–2003, 3164.7 million bp, ≈ 30,000 genes, 99.9 % identical, < 2 % coding, chromosome 1 = 2968 genes, Y = 231, 1.4 million SNPs.
- DNA fingerprinting: digest → electrophoresis → Southern blot → VNTR probe → autoradiography.
