# Practical · Mitosis in onion root tip — relations and facts

## Root-tip squash

:::formula Mitotic index
$\text{Mitotic index (\%)}=\dfrac{\text{dividing cells}}{\text{total cells counted}}\times100$
:::

:::formula Squash reagents
Fix: aceto-alcohol (1 : 3) · hydrolyse: 1N HCl, about 60 °C · stain: 2% aceto-carmine · mount: 45% acetic acid. Onion 2n = 16.
:::
