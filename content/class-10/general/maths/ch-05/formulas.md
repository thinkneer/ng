# Ch 5 · Arithmetic Progressions — formulas and key facts

AP: $a,\ a+d,\ a+2d,\ \dots$  ($a$ first term, $d$ common difference, $l$ last term)

:::formula Terms
$a_n=a+(n-1)d$<br>
$n$th term from the end $=l-(n-1)d$<br>
Number of terms $n=\dfrac{l-a}{d}+1$
:::

:::formula Sums
$S_n=\dfrac n2\left[2a+(n-1)d\right]=\dfrac n2\,(a+l)$<br>
$a_n=S_n-S_{n-1}$<br>
$1+2+\dots+n=\dfrac{n(n+1)}{2}$
:::

## Useful facts

- $a,b,c$ in AP $\iff2b=a+c$.
- Three terms in AP: $a-d,\ a,\ a+d$ (sum $3a$).
- Sum of first $n$ odd numbers $=n^2$; sum of first $n$ even numbers $=n(n+1)$.
- If $S_n$ is given as a formula: $a=S_1$, $d=S_2-2S_1$.

| Question says | Use |
|---|---|
| "the $n$th …", "in the last row" | $a_n$ |
| "in all", "total", "altogether" | $S_n$ |
| "which term is …" | solve $a_n=$ value for $n$ |
| "how many terms give the sum …" | solve $S_n=$ value (quadratic in $n$) |
