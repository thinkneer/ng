# Ch 8 · Introduction to Trigonometry — formulas and key facts

## Ratios (from the chosen acute angle θ)

:::formula The six ratios
$\sin\theta=\dfrac{O}{H}$   $\cos\theta=\dfrac{A}{H}$   $\tan\theta=\dfrac{O}{A}$<br>
$\operatorname{cosec}\theta=\dfrac{H}{O}$   $\sec\theta=\dfrac{H}{A}$   $\cot\theta=\dfrac{A}{O}$<br>
O = opposite, A = adjacent, H = hypotenuse;  $\tan\theta=\dfrac{\sin\theta}{\cos\theta}$
:::

## Standard values

| Angle | sin | cos |
|---|---|---|
| 0° | 0 | 1 |
| 30° | $\frac12$ | $\frac{\sqrt3}{2}$ |
| 45° | $\frac{1}{\sqrt2}$ | $\frac{1}{\sqrt2}$ |
| 60° | $\frac{\sqrt3}{2}$ | $\frac12$ |
| 90° | 1 | 0 |

| Angle | tan | cot |
|---|---|---|
| 0° | 0 | n.d. |
| 30° | $\frac{1}{\sqrt3}$ | $\sqrt3$ |
| 45° | 1 | 1 |
| 60° | $\sqrt3$ | $\frac{1}{\sqrt3}$ |
| 90° | n.d. | 0 |

| Angle | sec | cosec |
|---|---|---|
| 0° | 1 | n.d. |
| 30° | $\frac{2}{\sqrt3}$ | 2 |
| 45° | $\sqrt2$ | $\sqrt2$ |
| 60° | 2 | $\frac{2}{\sqrt3}$ |
| 90° | n.d. | 1 |

n.d. = not defined.

## Identities

:::formula Trigonometric identities
$\sin^2\theta+\cos^2\theta=1$<br>
$1+\tan^2\theta=\sec^2\theta$<br>
$1+\cot^2\theta=\operatorname{cosec}^2\theta$
:::

Rearranged forms: $1-\sin^2\theta=\cos^2\theta$ · $1-\cos^2\theta=\sin^2\theta$ · $\sec^2\theta-\tan^2\theta=1$ · $\operatorname{cosec}^2\theta-\cot^2\theta=1$.

## Special triangles

- 45°–45°–90°: sides $1:1:\sqrt2$.
- 30°–60°–90°: sides $1:\sqrt3:2$ (opposite 30° : opposite 60° : hypotenuse).

Not in boards 2026–27: trigonometric ratios of complementary angles.
