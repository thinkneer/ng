# Ch 13 · Statistics — formulas and key facts

:::formula Mean of grouped data
Direct: $\bar x=\dfrac{\sum f_ix_i}{\sum f_i}$<br>
Assumed mean: $\bar x=a+\dfrac{\sum f_id_i}{\sum f_i}$, $\ d_i=x_i-a$<br>
Step deviation: $\bar x=a+\dfrac{\sum f_iu_i}{\sum f_i}\times h$, $\ u_i=\dfrac{x_i-a}{h}$
:::

:::formula Mode
$\text{Mode}=l+\dfrac{f_1-f_0}{2f_1-f_0-f_2}\times h$<br>
$l$ lower limit of modal class · $f_1$ its frequency · $f_0$ class before · $f_2$ class after
:::

:::formula Median
$\text{Median}=l+\dfrac{\frac n2-cf}{f}\times h$<br>
$l$ lower limit of median class · $f$ its frequency · $cf$ cumulative frequency of the class before
:::

:::formula Empirical relationship
$3\ \text{Median}=\text{Mode}+2\ \text{Mean}$
:::

- Class mark $=\dfrac{\text{lower limit}+\text{upper limit}}{2}$; class size $h$ = upper − lower.
- Median class: first class with cf ≥ $\dfrac n2$. Modal class: highest frequency.
