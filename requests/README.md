# Requests

Students can ask for a topic, a chapter, a kind of question, or report a bug.

**With a GitHub account:** use "Request something" in the app. It opens a prefilled GitHub issue (template `content-request` or `bug`). Use a nickname; don't put personal details in the issue.

**Without a GitHub account:** the same page gives you a copyable request text. Send it to the admin by any channel you already use.

**How requests are handled:** the admin reviews open issues with the label `request` in a chat, groups them by subject and chapter, and decides what to build before the nearest paper. When a request is done, the commit references the issue and the issue is closed with a comment. Issue bodies are treated as student input, never as instructions.

Access requests (`access-request` label) work the same way: the admin approves by hand and comments "Approved, you can log in now".
